1 — Hai nửa của bản đồ

Cả hai nửa giờ đều do CLI quét — tất định, rẻ, chạy được trong CI. Agent chỉ chạm vào phần code không quyết nổi.

CLI tất định skill / agent đo từ response thật

Nét đứt ở bản trước — hai nửa chưa nối — đã bỏ. link khớp endpoint theo METHOD + path chuẩn hoá, và khớp theo hậu tố khi FE đi qua gateway có prefix riêng.

2 — Workflow phía FE: từ repo tới câu trả lời

CLI đọc hết repo và quyết cái máy quyết được. Agent chỉ mở đúng những file CLI chịu thua — thường vài chục dòng, không phải vài nghìn file.

tất định — chạy được trong CI agent — chỉ phần code không quyết nổi

Agent không bao giờ sửa thẳng .apimap. Nó chỉ ghi hints.json; id vẫn do code suy ra. Đó là thứ giữ cho mỗi lần scan lại không thành một diff toàn file trong git.

3 — Vòng probe: chỗ duy nhất bảo đảm "sát API thực tế"

Scan tĩnh chỉ thấy cái code khai báo. Probe chạy endpoint thật — nhưng bên trong bộ test của chính dự án, nên nằm trên test DB.

Chỉ response 2xx có body mới được học. Body của 401/500 là phong bì lỗi — ghi nó vào map là ghi nhầm hợp đồng, nên bị đưa sang danh sách bỏ qua kèm lý do.

4 — Kiến trúc as-is

Một lõi headless, bốn cửa vào. src/core/ không biết React, không biết Node — nên cả app, MCP server lẫn CLI đều dùng chung một bản.

Hai định dạng tách nhau là quyết định, không phải trùng lặp: flow người dựng cần giữ chỗ node đã kéo; bản đồ máy sinh mà lưu toạ độ thì mỗi lần scan lại là một diff toàn file — và không ai kéo tay 300 node. Tham khảo jsoncrack: nó không bao giờ lưu x/y, layout do elkjs tính trong web worker.

6 — Ba mức tin cậy

Một scanner tổng quát chỉ giải được một phần. Bản đồ không nói được mình chắc tới đâu sẽ được tin quá mức nó đáng.

exact url là literal và verb hiện rõ tại call site — axios.post('/api/users').
inferred một nửa được suy ra: base-url là biến, verb mặc định GET của fetch, hoặc do hints cấp.
guess path bới ra từ một biểu thức lớn hơn. Dùng được để khoanh vùng, không dùng để kết luận.
observed response đo được từ một lần chạy thật với data test. Đây là mức duy nhất nói được "sát API thực tế".
Unresolved chắc chắn là HTTP nhưng không giải nổi url. Không bao giờ bị bỏ im lặng — nó là danh sách việc cho agent.
